## Run it locally

Want to explore the code or run the site on your machine? You'll need **Node.js 20 or later** and **npm**.

```bash
git clone https://github.com/Rudra0075-ms/portfolio.git
cd portfolio/rudra-madhab-sahoo---portfolio
npm install
npm run dev
```

Open the local URL printed in your terminal.

### Useful commands

```bash
npm run lint    # Run the TypeScript checks
npm run build   # Create the production build
npm run preview # Preview the production build locally
```

The production build is generated in the `dist/` folder. GitHub Actions runs the checks and build for pushes and pull requests to the `main` branch.
